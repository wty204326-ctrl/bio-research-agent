# 中译中 plain-rewriter

用户的工作场景：术语密集的源文本（法规、毒理、方法学、文献），要**拿来给课题组用**而不是读原文。

## 三级简化（按用户反馈校准过的递进）

- **L1 忠实改写**（默认第一遍）：同义转述为日常汉语。保留全部技术事实，剥离行话外壳；必须保留的术语加括号一句话定义；短独立句优先，禁嵌套从句。**不要用新行话去解释旧行话。**
- **L2 极简要点**（用户说"更简单/再通俗点"时——这是信号：上一遍还是太浓）：压缩到 5-8 条一句话要点，每条独立成立，去到"给非本专业同学讲"的程度。
- **L3 类比版**（可选或用户点名）：用生活类比重述主干，只保主干不保细节，明确标注"类比，细节见 L1"。

## 结构化浓缩（主动产出，历史验证受欢迎）

- **表格浓缩**：流程/多方职责/条件分支 → 列表（谁-做什么-何时/条件-结果）。
- **ASCII 一页纸流程图**：主干流程 + 分支，等宽字符画，一屏内。示例骨架：
  ```
  [输入] --> {判断} --是--> [动作A] --> [输出]
               \--否--> [动作B] --> 回到{判断}
  ```

## 纪律

- 事实零损失原则只适用于 L1；L2/L3 的删减要明示"细节已略"。
- 数字、单位、方向（↑/↓、因果箭头）在任何层级都不许变。
- 输出顺序：先 L1（或直接表格/流程图），用户要更简单再下探——不要一步跳到 L3。
