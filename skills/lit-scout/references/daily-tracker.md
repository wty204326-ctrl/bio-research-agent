# 对接自有文献追踪系统（通用指引）

如果你已经有每日文献追踪自动化（定时任务/脚本），本 skill **只做按需主题检索**，不要重建或重复跑全量追踪。

## 对接要点

1. **识别用户意图**：说「每日文献/今天的文献」→ 查最新一期笔记或手动触发既有任务；说「调研某主题」→ 走 lit-scout 正常流程。
2. **增量语义**：若需手动补跑，先读最新笔记确定时间窗口终点（入库日 EDAT 口径），避免重复抓取。
3. **Zotero 入库**（用户要求时）：API key 放在安全凭据处（环境变量/凭据文件），不要写进代码或提交到仓库；集合 key 按用户配置读取。
4. **抓取脚本通用坑**（平台无关）：
   - 走系统代理可能导致长响应挂死，必要时强制直连 + 超时设置；
   - PubMed 标题解析保留空格（itertext + join(split())）；DOI 只取 ELocationID/PubmedData；
   - 关键词检索加词边界（如 `\bliver`）防 delivery 之类误报；
   - bioRxiv 分页会断：cursor 断点续爬 + 按 DOI 去重；作者串入库需包 `{"creatorType":"author","name":...}`。
5. **精读流程**：取全文（见 pdf-acquisition.md）→ 中英对照精读笔记落盘到用户指定的 Readings 目录。
